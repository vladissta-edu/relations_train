# Множества и отношения

Небольшой интерактивный тренажёр по теме «Отношения» из присланной лекции 2. Студент выбирает пример отношения, видит множество **A**, декартово произведение **A × A** и отношение **R ⊆ A × A**, затем меняет упорядоченные пары вручную. Выбранные пары одновременно показаны как множество, матрица и ориентированный граф.

Названия свойств соответствуют лекции: **рефлексивность**, **антирефлексивность**, **симметричность**, **антисимметричность**, **транзитивность**, **отношение эквивалентности**, **отношение частичного порядка**. Если свойство не выполняется, тренажёр указывает конкретную пару или цепочку пар. Для отношения эквивалентности показываются классы эквивалентности, образующие разбиение множества A.

## Открыть локально

Откройте `index.html` в браузере. Сборка, сервер, аккаунт и внешние библиотеки не нужны. Все файлы работают локально. При желании можно запустить локальный сервер из папки сайта: `python3 -m http.server 8000`, затем открыть `http://localhost:8000/`.

## Разместить на GitHub Pages

1. В организации `vladissta-edu` создайте публичный репозиторий с именем `relations_train`.
2. Загрузите в корень репозитория четыре файла: `index.html`, `style.css`, `app.js`, `README.md`.
3. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите основную ветку и папку **/(root)**, затем сохраните. Ссылка на опубликованный сайт появится на странице Pages после развёртывания.

После публикации адрес сайта будет `https://vladissta-edu.github.io/relations_train/`. Пути к файлам относительные. На GitHub Free для Pages нужен публичный репозиторий. Актуальные шаги есть в [официальной инструкции GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

## Идеи для занятия

- Откройте «Транзитивность» и уберите `(a, c)`: появится объяснение отсутствующей пары.
- Откройте «Симметричность» и уберите `(b, a)`: сравните стрелку с обратной.
- Откройте «Отношение эквивалентности»: сопоставьте R с разбиением на классы `{a, b}` и `{c}`.
- Откройте «Отношение частичного порядка» и добавьте `(b, a)`: проверьте антисимметричность.

Граф – одно из представлений отношения R: каждая стрелка соответствует выбранной упорядоченной паре.
